# Event Management System

A full-stack web application that simplifies event scheduling and registration management. 
The system allows users to view events through an interactive calendar, check event availability, and register for events.

This project was developed to practice full-stack development using React for frontend development and Django REST Framework for backend API design.

## Live Demo

Frontend:
https://event13.netlify.app/

Backend API:
https://event-management-system-0y0v.onrender.com


## Features

- Interactive event calendar view
- Display events by date and month
- View event details
- User event registration
- Event capacity management
- Automatic event status update:
  - Active
  - Full
  - Cancelled
- Prevent event scheduling conflicts based on date and location
- RESTful API communication between frontend and backend
